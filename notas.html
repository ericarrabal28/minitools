¿Cómo se calcula la media de las notas?

Para calcular una media, se suman todas las notas y se divide el resultado entre el número de notas.

Por ejemplo, si tienes un 6, un 7 y un 8, la media es 7.

¿Puedo utilizar notas con decimales?

Sí. Puedes introducir notas como 7,5, 8,25 o 9,75.
